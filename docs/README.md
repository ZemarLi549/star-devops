# docs

根目录统一文档目录。

## 结构

- `AI人效自动化与飞书采集统一架构方案.md`
- `AI人效自动化部署与操作指导.md`
- `AI人效自动化功能汇总与安全授权说明.md`
- `AI人效空间数据清理与保留策略.md`
- `api-gateway说明.md`
- `decisions/`
- `Nightingale前后端接入示例.md`
- `微服务接入总流程.md`
- `前后端接入清单.md`
- `templates/`

## 原则

- 所有跨项目、跨语言的接入说明统一放根目录。
- 涉及部署地址、账号、令牌、密钥、内网拓扑、端口策略等敏感或隐私信息的文档，继续放根目录 `docs/`。
- 通用操作手册、功能说明、日常 SOP、页面使用说明优先放 `sop-vdoc/docs/`。
- 子项目自身的使用说明仍保留在各自目录。

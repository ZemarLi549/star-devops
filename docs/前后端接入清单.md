# 前后端接入清单

## 前端

- 是否有路由入口
- 是否有工作台子页面
- 是否有权限点
- 是否有 API 封装
- 是否有空态和接入中提示
- 是否补文档

## 后端

- 是否有 `/healthz`
- 是否有 `application.example.yaml`
- 是否接入 Nacos
- 是否接入统一网关
- 是否把路由挂到 `KrakenD` 统一前缀
- 是否统一透传 `Authorization` 和必要业务 Header
- 是否考虑超时 / 限流 / 熔断
- 是否记录审计日志
- 是否补启动脚本

## 插件 / Go 客户端

- 是否走统一网关上报
- 是否支持二进制部署
- 是否有最小权限配置
- 是否隐藏敏感凭据
- 是否有清理脚本
- 是否有部署说明

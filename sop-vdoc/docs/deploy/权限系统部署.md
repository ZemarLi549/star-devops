## 部署说明

- 该文档适用于可观测团队现阶段向各业务线交付的星迹可观测平台部署建议和步骤
- 目前采用的云下部署方案为物理节点单节点部署
- 部署地址`/data/service`(建议)
- 本服务会创建数据库`aiops_resource`，auth-all服务默认端口：`9004`
- 前端UI组件部署步骤见《星迹可观测平台前端部署文档》
- 数据库部署步骤见《星迹可观测中间件部署文档》

## 数据库初始化

默认数据库已安装完成
* 建议：通过命令行执行，而非管理工具，不同管理工具可能存在命令报错问题。

### 1. Mysql数据库初始化

（1） 初始化脚本地址：auth-all.zip部署包中，`config/doc/sql/aiops_resource.init.sql`

（2） 执行脚本`aiops_resource.init.sql`（脚本包含创建数据库，创建表，初始化数据）

### 2. 达梦数据库初始化

（1） 初始化脚本地址：auth-all.zip部署包中，`config/doc/sql/dm.aiops_resource.init.sql`

（2） 执行脚本`dm.aiops_resource.init.sql`（脚本包含创建数据库，创建表，初始化数据）
### 3. doris数据库初始化

（1） 初始化脚本地址：auth-all.zip部署包中，`config/doc/sql/doris.aiops_resource.init.sql`

（2） 执行脚本`doris.aiops_resource.init.sql`（脚本包含创建数据库，创建表，初始化数据）

## 部署auth-all

***第一步***：上传部署包

将部署包里的auth-all.zip上传至`/data/service/`下，解压后会生成auth-all文件夹。

解压：

```
[root@iflyops-1 ~]# cd /data/service/
[root@iflyops-1 service]# unzip auth-all.zip
```

赋予启动脚本执行权限

```
[root@iflyops-1 service]# cd /data/service/auth-all
[root@iflyops-1 auth-all]# chmod 755 -R run.sh
```

***第二步***：修改配置

1、修改配置文件bootstrap.yml
```
[root@iflyops-1 auth-all]# cd /data/service/auth-all/config
[root@iflyops-1 auth-all]# vim bootstrap.yml
```
* 修改如下三个配置为对应环境的nacos配置
```yaml
auth:
  nacos:
    server-addr: 127.0.0.1:8848
    username: nacos
    password: bGMNFL$oML%M2jOt
```


***第三步***：启动auth-all

```
[root@iflyops-1 auth-all]# cd /data/service/auth-all
[root@iflyops-1 auth-all]# ./run.sh start
```

***第四步***：验证

```
[root@iflyops-1 auth-all]# ps -ef | grep auth-all
```

如果进程正常，则说明组件部署成功。

# 部署资源参考
<a name="Zh9Nk"></a>
## 单节点部署推荐：
建议需要采控的机器<200台、日均tps在100以下且日均存储<10G的业务 且不考虑高可用的情况下选择此部署方案，可申请2台两台16C32G的，或者一台32C 64G配置机器。

| 接入配置 | 参数    | 备注 |
| --- |-------| --- |
| 采控机器： | <200台 |  |
| 日志tps | 0~100 |  |
| 调用链qps | <10K  | 采样率100% (可灵活调整)日志记录率100% |
| 日志存储 | <10G  |  |
| 调用链存储 | <10G  |  |


| 中间件           | 配置 | 备注             | 机器配置推荐                                                        |
|---------------| --- |----------------|---------------------------------------------------------------|
| kafka         | 2G | 日志（可选）、调用链（可选） | CPU：16C<br />内存：32G 3200 * 1；<br />数据盘HDD：500G SATA 7.2K * 1； |
| zookeeper     |  | 调用链、日志         |                                                               |
| elasticsearch | Xms 4G Xmx 4G | 调用链            |                                                               |
| mysql         |  | 指标、采控、权限       |                                                               |
| redis         |  | 指标、权限          |                                                               |
| VM            | 4G | 指标             |                                                               |
| Doris         | 4G | 日志             |                                                               |
| nacos         | | 服务注册,所有应用      |                                                               |
| grafana       | | 日志 （可选）        |                                                               |
| xxl-job       | | 日志         |                                                               |


| 应用组件                   | 配置                | 备注         | 机器配置推荐：                                                                  |
|------------------------|-------------------|------------|--------------------------------------------------------------------------|
| oap                    | Xms 512M Xmx 1G   | 调用链组件      | <br /><br />CPU：16C<br />内存：32G 3200 * 1；<br />数据盘HDD：500G SATA 7.2K * 1 |
| auth-all               | Xms 256M Xmx 512M | 用户权限资源管理组件 |                                                                          |
| st-logplatform-service | Xms 512M Xmx 1G   | 日志组件       |                                                                          |
| st-n9e                 | 不涉及               | 监控系统组件     |                                                                          |
| st-gse                 | 不涉及               | 采控系统组件     |                                                                          |
| st-nodeman             | 不涉及               | 采控系统组件     |                                                                          |
| alarm-all              | Xms 1G Xmx 1G     | 告警组件       |                                                                          |



<a name="JXoHi"></a>
## 集群多节点部署推荐：
建议采控机器100~500台、tps100~200、日存储量在50G左右的业务选择高可用部署方案，可申请3台16c32g配置机器。

| 接入配置 | 参数 | 备注 |
| --- | --- | --- |
| 采控机器： | <500台 |  |
| 日志tps | 100~200 |  |
| 调用链qps | 10K+ | 采样率建议10%以内(可灵活调整)日志记录率90% |
| 日志存储 | <50G |  |
| 调用链存储 | <50G |  |

| 中间件                | 配置 | 备注             | 机器配置推荐                                                      |
|--------------------| -- |----------------|-------------------------------------------------------------|
| kafka *3           | 4G | 日志（可选）、调用链（可选） | CPU：16C<br />内存：32G 3200 * 1；<br />数据盘HDD：1T SATA 7.2K * 1； |
| zookeeper*3        |  | 调用链、日志         |                                                             |
| elasticsearch*3    | （Xms 8G Xmx  8G） | 调用链            |                                                             |
| mysql（主从）          |  | 指标、采控、权限       |                                                             |
| redis*3 哨兵         |  | 指标、权限          |                                                             |
| VM*3               |  | 指标             |                                                             |
| Doris*3（读高可用或写高可用） | 6G | 日志             |                                                             |
| nacos*3            | | 服务注册,所有应用      |                                                             |
| grafana            | | 日志 （可选）        |                                                             |
| xxl-job*2          | | 日志             |                                                             |


| 应用组件                   | 配置              | 备注 | 机器配置推荐                                                        |
|------------------------|-----------------| --- |---------------------------------------------------------------|
| oap                    | Xms 2G Xmx 4G   | 调用链组件 | CPU：16C<br />内存：32G 3200 * 1；<br />数据盘HDD：500G SATA 7.2K * 1； |
| auth-all               | Xms 512M Xmx 1G | 门户组件 |                                                               |
| st-logplatform-service | Xms 1G Xmx 3G   | 日志组件 |                                                               |
| st-n9e                    | 不涉及             | 监控系统组件 |                                                               |
| st-gse                    | 不涉及             | 采控系统组件 |                                                               |
| st-nodeman             | 不涉及             | 采控系统组件     |                                                               |
| alarm-all              | Xms 1G Xmx 2G   | 告警组件       |                                                               |

## 集群高可用部署推荐：
建议采控机器数量<1500台 、日志tps在200~300、调用链qps在10~20k且日存储量在100G以上的业务采用集群高可用部署方案，建议申请3台16C64G配置机器。

| 接入配置 | 参数 | 备注 |
| --- | --- | --- |
| 采控机器： | <1500台 |  |
| 日志tps | 200~300 |  |
| 调用链qps | 10K~20K | 采样率建议5%(可灵活调整) 日志记录率50% |
| 日志存储 | 80~100G |  |
| 调用链存储 | 80~100G |  |

| elasticsearch*3    | （Xms 8G Xmx  8G） | 调用链            |                                                           |

| redis*3 哨兵         |                  | 指标、权限          |                                                           |
| VM*3               |                  | 指标             |                                                           |
| Doris*3（读高可用或写高可用） | 16G              | 日志             |                                                           |
| nacos*3            |                  | 服务注册,所有应用      |                                                           |
| grafana            |                  | 日志（可选）         |                                                           |

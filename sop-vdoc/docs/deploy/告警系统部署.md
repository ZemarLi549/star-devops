## 部署说明

- 该文档适用于可观测团队现阶段向各业务线交付的星迹可观测平台部署建议和步骤
- 目前采用的云下部署方案为物理节点部署
- 部署地址/data/service(建议)
- 本服务会创建告警分析doris数据库aiops_alarm，告警管理mysql或达梦数据库aiops_alarm，告警服务默认端口：19000
- 前端UI组件部署步骤见《星迹可观测平台前端部署文档》
- 数据库部署步骤见《星迹可观测中间件部署文档》

## 机器配置

此配置为我方性能压测时服务器配置，后续文中所有配置项值均基于此硬件配置，业务方服务器配置不同时，可以调整配置项默认值以优化性能。

| 项目   | 配置                                                                    | 备注  |
| ---- | --------------------------------------------------------------------- | --- |
| 处理器  | 服务器要求 16 核 主频 2.2GHZ 数据库服务器要求 8 核 主频 2.2GHZ Web 服务器要求 8 核 主频 2.2GHZ   |     |
| 磁盘空间 | 服务器至少 600GB 以上 RAID1；数据库服务器至少 600GB 以上 RAID1 Web 服务器至少 600GB 以上 RAID1 |     |
| 内存   | 服务器要求 64GB 内存                                                         |     |
| 网络   | 1Gbps 网卡，并已设置好网络参数；采集器与 backend 之间通信推荐使用 10Gbps 网络以达到更优性能             |     |

## 部署步骤

- mysql,dm8,doris,nacos 的部署按照实际情况部署单机或集群，本文档省略，只介绍 alarm 相关组件部署步骤

### 执行初始化 SQL 脚本

SQL脚本目录：发布包 / 03_公共包 / 02_服务部署包 / alarm-all.zip（解压后得到alarm-all） / config / doc / sql /

#### 告警分析doris数据库

Doris FE前端页面，批量执行SQL脚本目录下，aiops_alarm_analyser_doris.init.sql中命令

#### 告警管理数据库Mysql（与达梦二选一）

Mysql客户端，批量执行脚本中命令，先执行aiops_alarm_manager_mysql.init.sql，后执行aiops_alarm_chain_mysql.init.sql

#### 告警管理数据库达梦（与Mysql二选一）

达梦客户端，批量执行脚本中命令，先执行aiops_alarm_manager_dm.init.sql，后执行aiops_alarm_chain_dm.init.sql

### 导入nacos配置

1.在nacos上新建命名空间为st-observable（如已存在，忽略此步骤）

2.将发布包/nacos配置/nacos_config.zip导入（如已导入，忽略此步骤，直接去改相关配置）

3.编辑Group为alarm-all,Data Id为application.yml和application-chain.yml的文件，注释待改项的属性

| 命名空间          | group     | dataId                |
| ------------- | --------- | --------------------- |
| st-observable | alarm-all | application.yml       |
| st-observable | alarm-all | application-chain.yml |

### 获取部署包

部署包位置：发布包 / 03_公共包 / 02_服务部署包 / alarm-all.zip

```
# 创建部署目录
> mkdir -p /data/service
> cd /data/service

# 上传alarm-all.zip至/data/service/

# 解压
> unzip alarm-all.zip
```

### 修改alarm-all/config/bootstrap.yml配置文件中，nacos地址server-addr，账号username，密码password
```yaml
CONFIG_NACOS_SERVER_ADDR: 127.0.0.1:8848
CONFIG_NACOS_USERNAME: nacos
CONFIG_NACOS_PASSWORD: bGMNFL$oML%M2jOt
CONFIG_NACOS_NAMESPACE: st-observable
ALARM_NACOS_SERVER_GROUP: alarm-all

spring:
  main:
    allow-circular-references: true
    allow-bean-definition-overriding: true
  application:
    name: alarm-all
  cloud:
    nacos:
      config:
        server-addr: ${CONFIG_NACOS_SERVER_ADDR}
        username: ${CONFIG_NACOS_USERNAME}
        password: ${CONFIG_NACOS_PASSWORD}
        file-extension: yaml
        namespace: ${CONFIG_NACOS_NAMESPACE}
        extension-configs[0]:
          group: ${ALARM_NACOS_SERVER_GROUP}
          data-id: application.yml
          refresh: true
        extension-configs[1]:
          group: ${ALARM_NACOS_SERVER_GROUP}
          data-id: application-chain.yml
          refresh: true
        enabled: true  # 开启/关闭使用配置中心配置
      discovery:
        server-addr: ${CONFIG_NACOS_SERVER_ADDR}
        username: ${CONFIG_NACOS_USERNAME}
        password: ${CONFIG_NACOS_PASSWORD}
        namespace: ${CONFIG_NACOS_NAMESPACE}
        enabled: true   # 开启/关闭使用注册中心
```

# 服务自动拉起
使用Supervisor配置服务的自动拉起
## Supervisor安装
使用yum方式部署，如果无法使用yum方式，可参考[官网](http://supervisord.org/installing.html) 部署文档

yum 安装 supervisor
```shell
yum install epel-release
yum install -y supervisor
```
修改supervisor配置
```shell
vim /etc/supervisord.conf
在[supervisord]中添加以下配置
minfds=655350                 ;
minprocs=65535                ;
```
启动服务并查看状态
```shell
systemctl enable supervisord # 开机自启动
systemctl start supervisord # 启动 supervisord 服务
systemctl status supervisord # 查看 supervisord 服务状态
ps -ef|grep supervisord # 查看是否存在 supervisord 进程
```

## 配置java服务自动拉起
以配置auth服务为例：
执行 vim /etc/supervisord.d/auth.ini
```shell
[program:auth]
command= /usr/local/jdk/bin/java  -server -Xms256m -Xmx256m -Xmn128m -XX:MetaspaceSize=128m -XX:MaxMetaspaceSize=256m -XX:-OmitStackTraceInFastThrow -XX:+HeapDumpOnOutOfMemoryError -XX:HeapDumpPath=/data/service/auth-service/logs/heapdump.hprof -Xloggc:/data/service/auth-service/logs/gc.log -verbose:gc -XX:+PrintGCDetails -XX:+PrintGCDateStamps -XX:+PrintGCTimeStamps -XX:+UseGCLogFileRotation -XX:NumberOfGCLogFiles=3 -XX:GCLogFileSize=1M -jar /data/service/auth-service/auth-service-1.0.0-SNAPSHOT.jar              ;
process_name=auth                                               ;
numprocs=1                                                      ;
directory=/data/service/auth-service/                           ;
umask=022                                                       ;
priority=999                                                    ;
autostart=true                                                  ;
autorestart=unexpected                                          ;
startsecs=3                                                     ;
startretries=5                                                  ;
exitcodes=0,2                                                   ;
stopsignal=TERM                                                 ;
stopwaitsecs=120                                                ;
user=ifly                                                       ;
redirect_stderr=true                                            ;
stdout_logfile=/data/public/supervisorlog/auth.log          ;
stdout_logfile_maxbytes=50MB                                    ;
stdout_logfile_backups=2                                        ;
stdout_capture_maxbytes=1MB                                     ;
stdout_events_enabled=false                                     ;
serverurl=AUTO                                                  ;
```


## 配置Doris拉起
### BE服务拉起
修改 start_be.sh 脚本，去掉最后的 & 符号
```shell
vim /path/doris/be/bin/start_be.sh
将 nohup $LIMIT ${DORIS_HOME}/lib/palo_be "$@" >> $LOG_DIR/be.out 2>&1 </dev/null &
修改为 nohup $LIMIT ${DORIS_HOME}/lib/palo_be "$@" >> $LOG_DIR/be.out 2>&1 </dev/null
```

创建 BE 的 supervisor 进程管理配置文件
```shell
vim /etc/supervisord.d/doris-be.ini

[program:doris_be]      
process_name=%(program_name)s      
directory=/path/doris/be/be
command=sh /path/doris/be/bin/start_be.sh
autostart=true
autorestart=true
user=root
numprocs=1
startretries=3
stopasgroup=true
killasgroup=true
startsecs=5
```

### FE服务拉起
修改 start_fe.sh 脚本，去掉最后的 & 符号
```shell
vim /path/doris/fe/bin/start_fe.sh 
将 nohup $LIMIT $JAVA $final_java_opt org.apache.doris.PaloFe ${HELPER} "$@" >> $LOG_DIR/fe.out 2>&1 </dev/null &
修改为 nohup $LIMIT $JAVA $final_java_opt org.apache.doris.PaloFe ${HELPER} "$@" >> $LOG_DIR/fe.out 2>&1 </dev/null
```

创建 FE 的 supervisor 进程管理配置文件
```shell
vim /etc/supervisord.d/doris-fe.ini

[program:doris_fe]
environment = JAVA_HOME="/path/jdk8"
process_name=%(program_name)s
directory=/path/doris/fe
command=sh /path/doris/fe/bin/start_fe.sh
autostart=true
autorestart=true
user=root
numprocs=1
startretries=3
stopasgroup=true
killasgroup=true
startsecs=10
```

### 启动服务
首先确定 Doris 服务是停止状态，然后使用 supervisor 将 Doris 自动拉起，然后确定进程是否正常启动
```shell
supervisorctl reload # 重新加载 Supervisor 中的所有配置文件
supervisorctl status # 查看 supervisor 状态，验证 Doris 服务进程是否正常启动

其他命令 : 
supervisorctl start all # supervisorctl start 可以开启进程
supervisorctl stop doris-be # 通过 supervisorctl stop，停止进程
```

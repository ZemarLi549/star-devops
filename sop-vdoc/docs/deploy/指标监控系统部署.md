## 部署说明

- 该文档适用于可观测团队现阶段向各业务线交付的星迹可观测平台部署建议和步骤
- 目前采用的云下部署方案为物理节点部署

### 机器配置

此配置为我方性能压测时服务器配置，后续文中所有配置项值均基于此硬件配置，业务方服务器配置不同时，可以调整配置项默认值以优化性能。

| 项目   | 配置                                                             | 备注 |
|------|----------------------------------------------------------------|----|
| 处理器  | 服务器要求16核 主频2.2GHZ 数据库服务器要求8核 主频2.2GHZ Web服务器要求8核 主频2.2GHZ      |
| 磁盘空间 | 服务器至少600GB以上 RAID1；数据库服务器至少600GB以上 RAID1 Web服务器至少600GB以上 RAID1 |
| 内存   | 服务器要求64GB内存                                                    |
| 网络   | 1Gbps网卡，并已设置好网络参数；采集器与backend之间通信推荐使用10Gbps网络以达到更优性能           |

### 安全规范

| 项目      | 配置                                                                       | 备注 |
|---------|--------------------------------------------------------------------------|----|
| 服务器安全   | 所有服务器仅开放需要的服务和端口，root密码严格控制范围，需要强密码策略，禁止root用户远程登录，开启命令审计服务，记录所有用户的操作命令。 |
| 网络安全    | 服务器之间使用内网连接传输数据。                                                         |
| 数据库帐号安全 | 数据库对应用系统建立专用帐号，不使用root登录。                                                |
| 数据安全    | 数据库只允许从WEB服务器和备份服务器访问，数据库需要定期备份。                                         |

## 部署步骤

- mysql、redis、victoria-metrics的部署按照实际情况部署单机或集群，本文档省略，只介绍n9e部署步骤

### 获取部署包

根据CPU架构选择 n9e_amd64.zip 或 n9e_arm64.zip部署包并解压

```shell
# 创建部署目录
mkdir -p /data/service/n9e_service
cd /data/service/

# 解压
unzip -d /data/service/n9e_service n9e_amd64.zip          # amd架构
或
unzip -d /data/service/n9e_service n9e_arm64.zip          # arm架构

# 授予可执行权限
chmod +x n9e start.sh stop.sh
```

### 执行初始化sql

1、数据库为MYSQL，找到部署包中的初始化脚本my_init.sql，用可视化工具连接Mysql数据库，执行脚本my_init.sql（脚本包含创建数据库，创建表，初始化数据）

2、数据库为DM达梦数据库，找到部署包中的初始化脚本dm_init.sql，用可视化工具连接达梦数据库，执行脚本dm_init.sql（脚本包含创建数据库，创建表，初始化数据）

3、找到部署包中的初始化脚本doris_init.sql，打开doris在线客户端（doris提供一个web客户端，可以执行SQL），在客户端中执行doris_init.sql脚本。


### 编辑配置文件

```
vim config.json
将其中的ip_addr、context_path、port、username、password、namespace_id修改为实际nacos的正确信息
```

```shell

```

```shell

```

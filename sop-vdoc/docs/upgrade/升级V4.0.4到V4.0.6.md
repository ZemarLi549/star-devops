## Nacos升级
nacos版本由2.2.1升级到2.2.3并且开启鉴权
2.2.1版本nacos数据库和2.2.3版本可共用，无需重置sql脚本。
**_第一步_**：停止原有nacos2.2.1版本服务

```
cd  /data/public/nacos/bin #具体目录以当前环境nacos部署目录为准
sh shutdown.sh
```
**_第二步_**：参考中间件部署文档中的 nacos2.2.3版本部署步骤部署nacos 下文以mysql存储为例，dm存储直接参考中间件部署文档关于nacos dm数据库部署部分
```
#单机
vim /data/public/nacos/conf/application.properties
#配置数据源 
spring.datasource.platform=mysql
spring.sql.init.platform=mysql
### Count of DB:
db.num=1
### Connect URL of DB:
db.url.0=jdbc:mysql://ip:port/库名?characterEncoding=utf8&connectTimeout=1000&socketTimeout=3000&autoReconnect=true&useUnicode=true&useSSL=false&serverTimezone=UTC #修改ip为mysql部署ip,端口为mysql配置的端口号
db.user.0=root #mysql登录名
db.password.0= #mysql登录密码

#注意nacos鉴权配置
nacos.core.auth.enabled=true
nacos.core.auth.plugin.nacos.token.cache.enable=false
nacos.core.auth.server.identity.key=${自定义，保证所有节点一致}
nacos.core.auth.server.identity.value=${自定义，保证所有节点一致}
nacos.core.auth.plugin.nacos.token.secret.key=${自定义，保证所有节点一致}
```
- 启动nacos  进入nacos bin目录
```shell
sh startup.sh -m standalone #-m standalone参数表示以单机模式启动Nacos
jps -l #查看是否启动成功
```
```
#集群
参考中间件部署文档中的nacos集群部署步骤
```

## 调用链系统升级
**_第一步_**：查找原部署安装目录
```
#获取进程id
jps -l | grep skywalking 
#获取部署目录
pwdx 进程id 
```
**_第二步_**：停止并备份原配置文件

```
#停止调用链服务
kill -9 进程id   
# 进入部署目录进行备份application.yml
cp apache-skywalking-apm-bin/config/application.yml apache-skywalking-apm-bin/config/application.yml.bak
```
**_第三步_**：修改配置文件

```
vim application.yml
```
1. 修改cluster为nacos 
```bash
cluster:
  selector: ${SW_CLUSTER:nacos}
  standalone:
  
  
   nacos:
    serviceName: ${SW_SERVICE_NAME:"SkyWalking_OAP_Cluster"}
    hostPort: ${SW_CLUSTER_NACOS_HOST_PORT:localhost:8848}
    # Nacos Configuration namespace
    namespace: ${SW_CLUSTER_NACOS_NAMESPACE:"st-observable"}
    # Nacos auth username
    username: ${SW_CLUSTER_NACOS_USERNAME:"nacos"}
    password: ${SW_CLUSTER_NACOS_PASSWORD:"nacos"}
    # Nacos auth accessKey
    accessKey: ${SW_CLUSTER_NACOS_ACCESSKEY:""}
    secretKey: ${SW_CLUSTER_NACOS_SECRETKEY:""}
    internalComHost: ${SW_CLUSTER_INTERNAL_COM_HOST:""}
    internalComPort: ${SW_CLUSTER_INTERNAL_COM_PORT:-1}

```

* 修改项
```
selector：nacos
serviceName:可以不修改，是nacos上服务列表的服务名称
hostPort： 根据nacos环境实际值填入
namespace:st-observable
username：根据nacos环境实际值填入
password：根据nacos环境实际值填入
```
2. 修改configuration为nacos
```
configuration:
  selector: ${SW_CONFIGURATION:nacos}
  nacos:
    # Nacos Server Host
    serverAddr: ${SW_CONFIG_NACOS_SERVER_ADDR:127.0.0.1}
    # Nacos Server Port
    port: ${SW_CONFIG_NACOS_SERVER_PORT:8848}
    # Nacos Configuration Group
    group: ${SW_CONFIG_NACOS_SERVER_GROUP:DEFAULT_GROUP}
    # Nacos Configuration namespace
    namespace: ${SW_CONFIG_NACOS_SERVER_NAMESPACE:skywalking-oap}
    # Unit seconds, sync period. Default fetch every 60 seconds.
    period: ${SW_CONFIG_NACOS_PERIOD:60}
    # Nacos auth username
    username: ${SW_CONFIG_NACOS_USERNAME:"nacos"}
    password: ${SW_CONFIG_NACOS_PASSWORD:"nacos"}
    # Nacos auth accessKey
    accessKey: ${SW_CONFIG_NACOS_ACCESSKEY:""}
    secretKey: ${SW_CONFIG_NACOS_SECRETKEY:""} 
```
* 修改项
```
selector：nacos
serverAddr： 根据nacos环境实际值填入
port：根据nacos环境实际值填入
group：skywalking-oap
namespace:st-observable
username：根据nacos环境实际值填入
password：根据nacos环境实际值填入
```
**_第四步_**：nacos管理台导入配置文件和修改
1. 在nacos上新建命名空间为st-observable（如已存在，忽略此步骤）
2. 将发布包/nacos配置/nacos_config.zip导入（如已导入，忽略此步骤，直接去改相关配置）
3. 修改dataid 为alarm.default.alarm-settings配置中的webhooks配置
  * 将skywalking-oap命名空间的alarm.default.alarm-settings配置复制过来
  * 删除skywalking-oap命名空间


**_第五步_**：启动服务
#在apache-skywalking-apm-bin/bin 目录下执行启动命令
```
sh oapService.sh 
```
**_第六步_**：访问验证
```
#访问管理端进行验证
http://ip/observer-center/skywalking/#/general?trace=true
```

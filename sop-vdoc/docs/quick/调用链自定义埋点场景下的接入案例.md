# 调用链自定义埋点场景下的接入案例
## 编码方式构建skywalking Trace
适用于AgentPlugin无法覆盖的场景
1. 引用 apm-toolkit-trace
```java
<dependency>
            <groupId>org.apache.skywalking</groupId>
            <artifactId>apm-toolkit-trace</artifactId>
            <version>8.16.0</version>
        </dependency>
```

### 使用指引：
<a name="a6D9W"></a>
#### 创建span
<a name="PLq8H"></a>
##### EntrySpan：
使用Tracer.createEntrySpan()创建span 用于SpanRef在skywalkingAgent内核中包含创建的span的引用。第一个参数是span名称，第二个参数是ContextCarrierRef，ContextCarrierRef是agent内部上下文的载体的引用。如果第二个参数不为空，则创建entrySpan时将执行extract 操作。具体参考inject/extract操作指引部分。
```java
import org.apache.skywalking.apm.toolkit.trace.Tracer;
...
SpanRef spanRef = Tracer.createEntrySpan("${operationName}", null);
```
<a name="HbuMV"></a>
##### localSpan：
使用Tracer.createLocalSpan()API创建localspan，唯一的参数是span的操作名称	
```java
import org.apache.skywalking.apm.toolkit.trace.Tracer;
...
    
SpanRef spanRef = Tracer.createLocalSpan("${operationName}");
```
<a name="CShRZ"></a>
##### ExitSpan：
使用Tracer.createExitSpan()API 创建ExitSpan<br />双参情况：第一个参数是span的操作名称，第二个参数是remotepeer，即退出操作的peer地址。
```java
import org.apache.skywalking.apm.toolkit.trace.Tracer;
...
      
SpanRef spanRef = Tracer.createExitSpan("${operationName}", "${remotePeer}");
```
三参情况：第一个参数是span的操作名称，第二个参数是ContextCarrierRef实例，第三个参数是远程peer。<br />ContextCarrierRef使用参考inject/extract操作指引部分。
```java
import org.apache.skywalking.apm.toolkit.trace.Tracer;
...
ContextCarrierRef contextCarrierRef = new ContextCarrierRef();
SpanRef spanRef = Tracer.createExitSpan("operationName", contextCarrierRef, "remotePeer");
```
<a name="LvVph"></a>
##### StopSpan：
使用Tracer.stopSpan()API停止当前span
```java
import org.apache.skywalking.apm.toolkit.trace.Tracer;
...
    
Tracer.stopSpan();
```

### Inject/Extract  ContextCarrier
inject/extract可以在不同进程之间传递上下文信息，包含 CarrierItem ContextCarrierRef 引用了ContextCarrier，CarrierItemRef引用了 CarrierItem 。这些CarrierItem的实例可以组成一个List。

- Tracer.inject()将当前上下文的信息注入到carrier
- Tracer.extract()从 contextCarrier 中提取信息。
- items()方法 来获取head的key和value。
- hasNext()方法来判断CarrierItemRef是否有值。
- next()获取下一个item
- getHeadKey获取当前item的key
- getHeadValue获取当item的value
- 使用setHeadValue实例CarrierItemRef设置当前项目的值
```java
ContextCarrierRef contextCarrierRef = new ContextCarrierRef();
Tracer.inject(contextCarrierRef);
Map<String, String> map = new HashMap<>();
CarrierItemRef next = contextCarrierRef.items();
while (next.hasNext()) {
    next = next.next();
    map.put(next.getHeadKey(), next.getHeadValue());
}
...
```
inject方法只能用于ExitSpan
```java
ContextCarrierRef contextCarrierRef = new ContextCarrierRef();
CarrierItemRef next = contextCarrierRef.items();
while ((next.hasNext())) {
	next = next.next();
	String value = map.get(next.getHeadKey());
	if (value != null){
		next.setHeadValue(value);
	}
}
Tracer.extract(contextCarrierRef);
```
创建 exit/entry span时可以执行inject/extract 方法  <br />extract方法通常用于mq消息传递上下文使用，目前看来非mq场景可以不适用该方法
```java
ContextCarrierRef contextCarrierRef = new ContextCarrierRef();
SpanRef spanRef = Tracer.createExitSpan("operationName", contextCarrierRef, "remotePeer");
Map<String, String> map = new HashMap<>();

    next = next.next();
    map.put(next.getHeadKey(), next.getHeadValue());
}
...
```

### Capture/Continue 上下文快照
Tracer.capture()可以capture  Segment的数据保存到ContextSnapshotRef，然后用于Tracer.continued()加载快照作为上游信息的引用方式。capture /ontinue 可以在多线程中追踪上下文
```java
import org.apache.skywalking.apm.toolkit.trace.Tracer;
...
    
ContextSnapshotRef contextSnapshotRef = Tracer.capture();
Thread thread = new Thread(() -> {
    SpanRef spanRef = Tracer.createLocalSpan("${operationName}");
    Tracer.continued(contextSnapshotRef);
      ...
      
});
thread.start();
thread.join();
```

### 添加span的 Tag和Log信息
<a name="zKu5b"></a>
#### 使用SpanRef.log 记录信息
```java
import org.apache.skywalking.apm.toolkit.trace.SpanRef;
...
  
SpanRef spanRef = Tracer.createLocalSpan("${operationName}");
  
// Throwable parameter
spanRef.log(new RuntimeException("${exception_message}"));  
  
// Map parameter
Map<String, String> logMap = new HashMap<>();
logMap.put("event", "${event_type}");
logMap.put("message", "${message_value}");
spanRef.log(logMap);  
```
使用SpanRef.tag添加tag，tag参数是k，v
```java
import org.apache.skywalking.apm.toolkit.trace.SpanRef;
...
  
SpanRef spanRef = Tracer.createLocalSpan(operationName);
spanRef.tag("${key}", "${value}");
```

<a name="TxrDj"></a>
### Async 场景下记录span信息
使用SpanRef 的prepareForAsync方法  可以使span在asyncFinish方法调用之前保持开启状态，然后在指定代码位置显式调用asyncFinish来结束当前span
```java
import org.apache.skywalking.apm.toolkit.trace.SpanRef;
...
  
SpanRef spanRef = Tracer.createLocalSpan("${operationName}");
spanRef.prepareForAsync();
// the span does not finish because of the prepareForAsync() operation
Tracer.stopSpan();
Thread thread = new Thread(() -> {
    ...
      
    spanRef.asyncFinish();
});
thread.start();
thread.join();
```

### ActiveSpan使用

- 添加自定义标记，ActiveSpan.tag("key", "val")
- ActiveSpan.error()将当前span标记为错误状态。
- ActiveSpan.error(String errorMsg)当前span标记为错误状态同时传入msg。
- ActiveSpan.error(Throwable throwable)当前span标记为错误状态抛出异常。
- ActiveSpan.debug(String debugMsg)在当前span中添加debug日志消息。
- ActiveSpan.info(String infoMsg)在当前span中添加info日志消息。
- ActiveSpan.setOperationName(String operationName)自定义操作名称可以覆盖CreateSpan时塞入的operationName参数。
```java
ActiveSpan.tag("my_tag", "my_value");
ActiveSpan.error();
ActiveSpan.error("Test-Error-Reason");

ActiveSpan.error(new RuntimeException("Test-Error-Throwable"));
ActiveSpan.info("Test-Info-Msg");
ActiveSpan.debug("Test-debug-Msg");

ActiveSpan.setOperationName("${opetationName}");
```

### sw8构建
使用Tracer.createExitSpan 方法创建exitspan第二个参数传入contextCarrierRef<br />使用contextCarrierRef.items()方法消费数据，构建到请求协议头中，在请求中携带。
```java
ContextCarrierRef contextCarrierRef = new ContextCarrierRef();
//createExitSpan
        SpanRef exitSpanRef  =  Tracer.createExitSpan("ExitOperationName",contextCarrierRef,"peer");
        //SpanRef exitSpanRef =  Tracer.createExitSpan("ExitOperationName","sipTest:9090");
        exitSpanRef.tag("exit_ref_tag","exit_ref_tag_value");
        ActiveSpan.tag("exit_tag","exit_value");
        ActiveSpan.setOperationName("Exit_OperationName");

        CarrierItemRef next = contextCarrierRef.items();
        while (next.hasNext()) {
            next = next.next();
            String headKey = next.getHeadKey();
            String headValue = next.getHeadValue();

            System.out.println("headKey:" + headKey);
            System.out.println("headValue:" + headValue);
        }
```
以http调用为例 在被调用方 使用contextCarrierRef获取sw8数据。
```java
RequestAttributes requestAttributes = RequestContextHolder.getRequestAttributes();
        assert requestAttributes != null;
        HttpServletRequest request = ((ServletRequestAttributes) requestAttributes).getRequest();
         String header =  ((ServletRequestAttributes) requestAttributes).getRequest().getHeader("sw8");


        //提取快照
        ContextCarrierRef contextCarrierRef = new ContextCarrierRef();
        CarrierItemRef next = contextCarrierRef.items();
        while (next.hasNext()) {
            next = next.next();
            next.setHeadValue(request.getHeader(next.getHeadKey()));
        }
    
```

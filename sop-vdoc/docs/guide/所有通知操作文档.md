# 所有通知

所有通知展示了向用户发送的告警通知的相关内容。

所有通知主页：展示了所有通知的基本信息，用户可以根据告警ID和告警级别进行条件搜索。

![所有通知.png](imgs%2Falarm%2F%E6%89%80%E6%9C%89%E9%80%9A%E7%9F%A5.png)

所有通知详情：点击告警ID之后会跳转到通知详情页面，展示了通知对应告警的基本信息，还有通知的时间和策略：

![所有通知—详情.png](imgs%2Falarm%2F%E6%89%80%E6%9C%89%E9%80%9A%E7%9F%A5%E2%80%94%E8%AF%A6%E6%83%85.png)

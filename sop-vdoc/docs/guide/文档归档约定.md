# 文档归档约定

## 目标

统一鑫图平台后续的文档落点，避免同类文档分散在不同目录里难以维护。

## 归档规则

### 放到 `sop-vdoc/docs/` 的文档

适合放这里的内容：

- 页面操作手册
- 用户使用说明
- 功能介绍
- 日常 SOP
- 常规接入说明
- 不包含敏感部署信息的通用流程文档

### 放到根目录 `docs/` 的文档

适合放这里的内容：

- 部署细节
- 内网地址
- 防火墙端口
- token / 密钥 / 账号策略
- 微服务实际接入细节
- 生产或准生产拓扑
- 任何带隐私或敏感信息的文档

## 当前项目建议

- `api-gateway` 原理、接入策略、熔断限流说明：可同步一份到 `sop-vdoc/docs/`
- 具体部署步骤、内网地址、令牌策略：保留在根目录 `docs/`
- 飞书采集插件普通用户使用说明：可整理到 `sop-vdoc/docs/`
- 插件敏感接入参数和内网口径：保留在根目录 `docs/`

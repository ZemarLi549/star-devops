# cpo-feishu-collector-plugin 脚本集合

这份文档汇总当前插件可直接使用的脚本，方便你自己部署和交付给其他用户。

## 1. 脚本列表

| 脚本 | 作用 |
| --- | --- |
| `bin/install.sh` | 初始化目录和默认配置 |
| `bin/build.sh` | 构建本机 Go 客户端程序 |
| `bin/authorize.sh` | 使用当前用户自己的飞书应用完成本机授权 |
| `bin/package.sh` | 生成 Linux / macOS / Windows 下载包 |
| `bin/quick-deploy.sh` | 一键初始化并给出授权与启动步骤 |
| `bin/start.sh` | 在已授权前提下启动后台定时采集 |
| `bin/stop.sh` | 停止后台采集 |
| `bin/collect-e0028517.sh` | 立即采集试点用户 `E0028517` |
| `bin/show-report.sh` | 查看用户最新日报和当前数据目录 |
| `bin/clean-history.sh` | 清理飞书聊天原始记录、日报、会议、文档等历史文件 |

## 2. 推荐使用顺序

### 2.1 初始化

```bash
bash bin/install.sh E0028517
```

### 2.2 一键部署

```bash
bash bin/quick-deploy.sh E0028517
```

### 2.3 先授权

```bash
bash bin/authorize.sh E0028517
```

### 2.4 试点采集

```bash
bash bin/collect-e0028517.sh
```

### 2.5 查看结果

```bash
bash bin/show-report.sh E0028517
```

### 2.6 后台定时运行

```bash
bash bin/start.sh
```

### 2.7 打包下载物

```bash
bash bin/package.sh
```

### 2.8 停止

```bash
bash bin/stop.sh
```

## 3. 历史数据目录

当前统一落到：

```text
data/<userId>/
├─ raw-chat/                  # 预留飞书聊天原始记录目录
├─ meta/                      # 心跳等元数据
├─ reports/
│  ├─ daily/
│  │  ├─ latest-report.json
│  │  ├─ latest-report.md
│  │  └─ history/             # 日报历史
│  ├─ meeting/
│  │  └─ history/             # 会议历史
│  └─ document/
│     └─ history/             # 文档历史
├─ archive/                   # 预留归档目录
├─ latest-report.json         # 兼容旧路径
├─ latest-report.md           # 兼容旧路径
└─ heartbeat.json             # 兼容旧路径
```

说明：

- 当前第一版主要生成日报历史。
- `raw-chat/`、`meeting/history/`、`document/history/` 目录先预留，后续真实飞书采集会直接写进去。
- 为兼容旧文档，根目录仍保留 `latest-report.json`、`latest-report.md` 和 `heartbeat.json`。
- 机器人、工作流、审批流、应用通知交互默认统一排除，不写入个人统计口径。

## 4. 清理脚本

### 4.1 清理单个用户

```bash
bash bin/clean-history.sh --user E0028517
```

作用：

- 清理 `7` 天以前的历史文件
- 不会删除最新日报
- 不会删除 `.gitkeep`

### 4.2 先预览不删除

```bash
bash bin/clean-history.sh --user E0028517 --dry-run
```

### 4.3 清理所有用户

```bash
bash bin/clean-history.sh --all
```

## 6. 注意

- 当前优先做真实聊天授权采集。
- 会议和文档采集保持独立开关，不影响聊天统计。
- 后面真实授权接入后，`raw-chat/`、会议历史、文档历史目录会继续沿用，不需要再改清理脚本。
- 普通用户页面和下载页不展示公共机器人密钥、公共飞书 App Secret、上传 token。
- `bin/build.sh` 和 `bin/package.sh` 会优先尝试 `~/.g/go/bin/go`，不要求手工执行 `npm`。
